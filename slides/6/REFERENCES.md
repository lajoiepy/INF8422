# Références pour approfondir

Les figures et leurs recadrages sont documentés dans [images/SOURCES.md](images/SOURCES.md).

- Godard et al., [Digging Into Self-Supervised Monocular Depth Estimation](https://arxiv.org/abs/1806.01260), ICCV 2019.
- Chen et al., [A Simple Framework for Contrastive Learning of Visual Representations](https://arxiv.org/abs/2002.05709), ICML 2020.
- Grill et al., [Bootstrap Your Own Latent](https://arxiv.org/abs/2006.07733), NeurIPS 2020.
- He et al., [Masked Autoencoders Are Scalable Vision Learners](https://arxiv.org/abs/2111.06377), CVPR 2022.
- Pang et al., [Masked Autoencoders for Point Cloud Self-supervised Learning](https://arxiv.org/abs/2203.06604), ECCV 2022.
- [How Does It Feel? Self-Supervised Costmap Learning for Off-Road Vehicle Traversability](https://arxiv.org/abs/2209.10788), prépublication 2022 ; proprioception et cartes de coût.
- [Self-Supervised 3D Traversability Estimation with Proxy Bank Guidance](https://arxiv.org/abs/2211.11201), prépublication 2022 ; supervision partielle de la traversabilité.
- Levine et al., [Learning Hand-Eye Coordination for Robotic Grasping with Deep Learning and Large-Scale Data Collection](https://arxiv.org/abs/1603.02199), prépublication 2016.
- Teed et Deng, [RAFT](https://arxiv.org/abs/2003.12039), ECCV 2020.
- Khurana et al., [Point Cloud Forecasting as a Proxy for 4D Occupancy Forecasting](https://openaccess.thecvf.com/content/CVPR2023/papers/Khurana_Point_Cloud_Forecasting_as_a_Proxy_for_4D_Occupancy_Forecasting_CVPR_2023_paper.pdf), CVPR 2023 ; prévision et rendu de retours LiDAR.

Les animations illustrent les mécanismes avec des données synthétiques ; leurs courbes ne reproduisent pas les performances rapportées dans ces articles.
