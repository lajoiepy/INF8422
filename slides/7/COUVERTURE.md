# Objectifs et contenu

Chaque ligne regroupe les objectifs couverts par le fichier de section correspondant. Les titres individuels sont disponibles dans `coverage.json`.

## Comment les modèles de fondation sont construits

Échelle données/paramètres/calcul ; transfert sans exemple/vocabulaire ouvert ; CLIP, DINO et SAM avec versions ; tokens, autorégression, génération ; encodeur-projecteur-LLM et instructions ; prompting, sonde, ajustement fin, adaptateurs, LoRA ; distillation/quantification ; latence, hallucinations et limites physiques.

## Modèles de fondation géométriques

Relative/métrique ; Depth Anything et Metric3D ; invariance échelle/décalage ; pointmaps, DUSt3R, MASt3R ; confiance pondérée ; VGGT et attention alternée ; permutation π³/π³X ; MapAnything entrées hétérogènes ; rayons et Depth Anything 3 ; données réelles/synthétiques ; têtes de rendu ; mémoire CUT3R ; TALO, SLAM/relocalisation et cohérence longue durée.

## Du 2D au 3D sémantique

Projection des caractéristiques ; espaces CLIP/DINO ; fusion multivue et occultations ; cosinus et requêtes ; masques SAM et association d’instances ; cartes et champs ; NeRF, rendu volumique, Gaussian splatting ; distillation de caractéristiques ; évaluation de carte interrogeable.

## Relations entre objets

Triplets supervisés et GNN ; nœuds à vocabulaire ouvert ; légendes VLM et relations LLM ; ConceptGraphs ; prompts/JSON structurés et validation ; mesures versus sémantique ; bâtiment/étage/pièce/objet ; recherche et planification ; hallucinations ; vérité terrain incomplète.

## Intentions humaines

Personnes, identités et pose ; trajectoires futures enregistrées ; interactions sociales et attention ; multimodalité ; mélanges, winner-takes-all, CVAE (ELBO, réparamétrage, loi a priori) et diffusion (bruitage, perte, génération) ; ADE/FDE/minADE/minFDE ; VLM vidéo et relations personne-objet ; latence et coût des erreurs ; ouverture VLA.
