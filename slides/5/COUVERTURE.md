# Objectifs et contenu

Chaque ligne regroupe les objectifs couverts par le fichier de section correspondant. Les titres individuels sont disponibles dans `coverage.json`.

## Bases de l’apprentissage

Risque empirique ; séparations par trajets ; neurone et MLP ; activations ; L1/L2, softmax et entropie croisée ; gradient calculé ; rétropropagation ; SGD, momentum, Adam ; taux ; surapprentissage ; régularisation, dropout, arrêt et augmentations.

## Étiquettes denses

Segmentation image/points/BEV ; convolution, canaux, stride, champ réceptif, pooling, équivariance ; ResNet et BatchNorm ; encodeur-décodeur et U-Net ; pondération des classes ; IoU/mIoU ; PointNet et PointNet++ ; voxels creux ; lift-splat ; transfert ImageNet.

## Représentations objet

Boîtes 2D/3D ; pertes multi-tâches, L1 lissée et focale ; ancres/NMS, deux étapes et une étape, centres ; piliers/LiDAR/caméra/fusion ; instances ; attention QKV, multi-têtes, croisée, positions, transformer ; DETR et appariement ; mAP ; pose 6-DoF, PnP, rendu-comparaison, catégorie ; quaternion/6D/symétries ; ADD/ADD-S ; annotation hors ligne, pseudo-étiquettes, EMA et distillation.

## Cartes HD

Géométrie, types et topologie ; carte vectorielle locale ; polylignes et permutations admissibles ; requêtes hiérarchiques ; MapTR ; attention déformable ; BEV temporelle ; graphes et passage de messages ; cartes SD a priori, aérien et flotte ; bruit et péremption ; changement ; Chamfer et AP.

## Reconnaissance de lieux

Recherche image/LiDAR ; représentation vectorielle, siamois, pertes contrastive/triplet ; négatifs difficiles ; GeM et NetVLAD ; GPS faible et apprentissage multi-instances ; index approximatifs ; vérification géométrique ; Recall@N ; saisons, météo, heure et point de vue.
